本页只记录运行限制和风险提示，不构成法律结论。目标网站条款、数据类型、访问方式、
个人信息处理和适用法律均需人工合规审查。

## 注意事项

1. **浏览器依赖**：Boss直聘爬虫需要 Chrome + DrissionPage，多公司爬虫需要 Playwright + Chromium
2. **反爬机制**：部分招聘网站有较强的反爬措施，爬取频率过高可能导致 IP 被封
3. **猎聘登录**：需要手动获取登录 Cookie，无法通过 API 自动登录
4. **数据量**：多公司全量爬取可能产生数千条数据，耗时较长（10-30 分钟）
5. **合规使用**：robots.txt 和使用条款是人工审查输入；项目负责人需确认授权并合理控制频率
