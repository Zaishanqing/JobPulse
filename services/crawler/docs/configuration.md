# 爬虫配置

> 文档类型：指南
> 维护状态：active
> 适用范围：`JobPulse/services/crawler/`
> 事实源：`config.py`、数据库初始化代码、路由与站点适配器
> 责任角色：模块维护者
> 最后复核：2026-07-27


数据库、认证密钥、站点凭证、Cookie 路径和请求频率均属于部署配置。具体安装、
数据库初始化和启动步骤见[运行与部署](operations.md)。

- 不提交真实密码、JWT 密钥、Cookie 或站点账号。
- 猎聘 Cookie 默认使用被 Git 忽略的本地文件，也可通过
  `LIEPIN_COOKIES_FILE` 指定。
- 仓库中曾出现过的登录 Cookie 应视为已经泄露；必须在对应站点主动退出登录，
  或重新登录以使旧登录会话失效，不能只删除仓库文件。
- 配置完成只证明参数可加载；真实登录、访问许可和站点稳定性尚未确认。
